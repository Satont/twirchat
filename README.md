## Installation

### Linux

To install the latest stable version on Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/Satont/twirchat/main/scripts/install-linux.sh | bash
```

After installation, the app is available in the applications menu and via the `twirchat` command in the terminal. You can also download the standalone `.AppImage` directly from the [Releases](https://github.com/Satont/twirchat/releases/latest) page.

### Windows

1. Download the latest Windows Setup `.exe` from [Releases](https://github.com/Satont/twirchat/releases/latest).
2. Run the installer to install TwirChat.

### macOS

1. Download the latest macOS universal archive from [Releases](https://github.com/Satont/twirchat/releases/latest).
2. Extract the archive and move `TwirChat.app` to your `/Applications` folder.
